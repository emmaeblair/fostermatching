# Pet Adoption Matching App

A dating-app style discovery platform for adoptable rescue cats and dogs. Instead of digging through static directories like Petfinder, adopters get a fun, personality-driven swipe/scroll experience powered by rescue APIs, smart filtering, and AI-assisted lifestyle matching.

*(Note: Repo is named `fostermatching` from an earlier concept, but the product is focused strictly on **pet adoption discovery** for adopters.)*

## Project Structure

- [`product/`](./product/README.md) — Product management artifacts: problem framing, adopter personas, JTBD, MVP scoping, and PM learning log.
- [`design/`](./design/README.md) — Design inspiration, moodboards, UX mechanics, color theory notes, and mockups.
